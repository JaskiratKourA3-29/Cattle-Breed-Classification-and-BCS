# Cattle Breed Classification and Body Condition Scoring System

## Overview

This project uses Deep Learning and Computer Vision to identify cattle breeds and estimate Body Condition Score (BCS) from uploaded cattle images.

## Features

- User Authentication
- Cattle Breed Classification
- Body Condition Scoring
- Analysis History
- Breed Library
- Statistics Dashboard

## Technologies Used

- Python
- Streamlit
- TensorFlow/Keras
- MobileNetV2
- OpenCV
- NumPy

## Project Structure

```text
app.py
breed_model.keras
labels.json
users.json
requirements.txt
```

## Installation

```bash
pip install -r requirements.txt
```

## Run Application

```bash
streamlit run app.py
```

## Model

The cattle breed classification model is based on MobileNetV2 Transfer Learning and was trained using Google Colab.
